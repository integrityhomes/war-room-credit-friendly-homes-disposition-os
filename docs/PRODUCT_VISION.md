# Product Vision

Credit Friendly Homes Disposition OS is a focused internal system for moving owner-financed homes faster while building a proprietary consumer-buyer database.

## Core promise
Enter a property once, verify the facts once, approve once, and let the system prepare or launch every allowed marketing channel, capture buyers, match them to inventory, create follow-up tasks, and stop campaigns when the property sells.

## Competitive edge
The durable advantage is not generic content generation. It is the private operating data created over time: which sources produce qualified buyers, which buyers act, which payment and down-payment ranges convert, which cities have waiting demand, which messages create calls, and which campaigns produce applications and deposits.

## Scope
This repository is exclusively for Credit Friendly Homes owner-finance disposition. Wholesale disposition belongs in a different system.
