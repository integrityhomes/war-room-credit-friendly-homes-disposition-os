# Portfolio disposition attention

No address lookup is required. Ask “Give me a plan for every stale property”,
“What properties need help selling?” or “What needs my attention?”. Every qualifying
yellow property is included, with a practical ranked plan. Recorded facts, possible
causes, missing evidence and proposed actions remain separate. Detailed facts and
source events are under the existing expandable evidence view.

The existing two-hour checker still evaluates every validated property and preserves
its first yellow observation. It now saves a diagnosis for every stale attention item
in the same local checkpoint. It reads additional canonical contacts, communications,
tasks, deals and activities only when stale items exist. Failed ancillary reads are
recorded as missing evidence; the property assessment continues without fabricated
counts. No new scheduler, canonical store, schema or credentials are introduced.

Automatic attention begins at 10 days, escalates at 14 and 21, and excludes white,
unavailable and unverified-color inventory. Each property/marketing period has a
stable attention item ID. Existing threshold event IDs suppress repeat notifications;
each check replaces the current queue and plans. White/sold transitions remove items.
The existing prospective observation dates are neither reset nor backdated.

Ranking orders threshold severity first, then recorded blockers, unfinished follow-up
work, recorded objections, marketing age and time since the last observed price/terms
change. Missing activity is not evidence of weak marketing. A buyer objection supports
a possible cause, not a market valuation. Every plan includes concrete next steps and
a proposed 72-hour outcome review, without activating a new schedule or creating tasks.

Any selected yellow property can be diagnosed before 10 days: “What would make this
sell?” or “What should we change?”. White remains pre-marketing inventory.

Numerical review options calculate implied principal from recorded asking price and
down payment. If an explicit recorded amortization period and rate also exist, a
fixed-rate principal-and-interest calculation is shown with assumptions. No arbitrary
discount, market/comparable price range, amortization term or buyer payment target is
invented. Taxes, insurance, fees and balloon provisions must be verified before any
contract/payment decision. These are review calculations, never applied terms.

All portfolio analysis is read-only. No messages, campaigns, price/terms/status updates,
task creation, spending, publishing, or other consequential actions are triggered.
